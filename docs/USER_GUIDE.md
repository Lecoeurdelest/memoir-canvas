# Using Memoir Canvas

> Status: outline. Write it out in `TASK-029`, alongside the Devpost submission text.

Memoir Canvas is a book. You tell family stories, an agent writes them down — but it records
**recollections**, not **facts**, and it tells you where it is unsure.

## Opening it for the first time

The app ships with a sample archive (fictional) so you can see immediately how it works. Your
own data lives in your own browser — there is no server, and nobody else can see it.

## Telling a memory

Talk to the agent the way you would talk to a person: *"Grandma moved from Hội An up to Đà Nẵng
around 1972 and opened a tailor shop."*

The agent adds the person, the place and the event to the book, and labels it **Oral
recollection** — because that is what you told it, and nothing has confirmed it yet. The word
"around" is preserved, not rounded off to 1972.

## The five labels

| Label | Meaning |
|---|---|
| **Uncertain** | just recorded, nothing behind it yet |
| **Oral recollection** | someone in the family said so |
| **Document-supported** | a photo or a document backs it |
| **Conflicting** | two sources disagree |
| **Confirmed** | someone in the family settled it |

## When two sources disagree

You add a photograph with 1974 written on the back. The book **tears along that page**, and it
**will not close**.

The agent will **not** pick a year for you. Instead it proposes a specific question for a
specific person: *"Ask Uncle Ba: was the photo taken before or after the move?"*

This is what makes Memoir Canvas different. An AI that guesses hands you a tidy answer; Memoir Canvas hands
you the right question.

## Closing a disagreement

Only **you** can. Open the conflict page, choose the right side, write down why. The tear
heals, the label becomes **Confirmed**, and the name of the person who confirmed it appears on
the page.

There is no way for the agent to do this step for you — not even if you ask it to.

## Reviewing what happened

The audit panel records every operation: who did it, when, and on what basis. Including the
times the agent tried something and was refused.
